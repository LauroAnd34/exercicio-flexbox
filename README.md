# Exercício Flexbox

Exercício da trilha de desenvolvimento web (+Robotic): organizar as quatro peças de cada um dos 8 quadros de um jeito diferente usando Flexbox.

- Online: https://lauroand34.github.io/exercicio-flexbox/
- No computador: baixe o repositório e abra o `index.html` no navegador.

## O que cada quadro usa

| Quadro | Solução |
|---|---|
| 1 | `justify-content: space-evenly` com as peças no topo |
| 2 | `flex-direction: column-reverse` (ordem invertida, encostado embaixo) |
| 3 | `flex-direction: column` + `justify-content: space-between` + `align-items: center` |
| 4 | `justify-content: center` + `align-items: center` |
| 5 | `justify-content: flex-end` + `align-items: flex-end` |
| 6 | `flex-grow: 1` na segunda peça |
| 7 | Peças no topo, terceira peça branca |
| 8 | `flex-wrap: wrap` com peças grandes formando uma grade 2x2 |
